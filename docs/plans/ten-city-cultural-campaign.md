# 十城街景文化冒险战役 v2

> 本文只定义 `?campaign=v2` 的线性十城×八点战役。新的三十六点纽约分支冒险属于 `?campaign=v3`，见 [纽约长篇街景冒险 v3 计划](./new-york-longform-campaign-v3.md)；不得用 v3 范围改写 v2 存档或验证契约。

## 交付范围

入口为 `?campaign=v2`。旧战役仍是默认入口，直到纽约纵切和至少两座后续城市完成
人工体验及路线验收。十座城市维持既有顺序，每城八个锚点，共 80 点；每章固定经过
观察收集、对话、普通战斗、文化线索解谜、历史答题、环境解谜、精英战和章末综合挑战。

## 分批验收

1. 纽约：验证内容模型、四类非战斗互动与两类战斗阶段、来源脚注、存档迁移和街景回退。
2. 东京、巴黎、雅典。
3. 莫斯科、阿格拉、马丘比丘。
4. 开普敦、迪拜、悉尼。

当前仓库已经提供全部十城的可运行内容骨架，精确坐标仍标记为
`needs-live-check`。只有在线验证成功后才可改成 `verified`。

## 验收门槛

- `CITY_CHAPTERS` 恰好 10 章、80 个唯一锚点；不包含语言题或当地表达文案。
- 每条事实有机构、链接和最后核验日期；HUD 以“史实”和“奇幻”分栏展示。
- 所有互动可用触控、鼠标和数字键；第 4 点以地点史实解谜替代语言任务。
- 答题浮窗背景为 70% 透明，文字和按钮保持清晰；非战斗阶段保留 Google 街景原生方向箭头与点击移动。
- 错误三次逐级提示并自动解除阻塞。
- 对话选择仅改变本章提示、精英数量或掌握度，第八点统一汇合。
- 街景无链接、超时、坐标失效或漂移时显示原因并继续章节。
- 390×844 下互动、来源脚注和战斗界面不重叠。

## 运行与验证

```sh
npm test
npm run build
npm run dev -- --host 127.0.0.1
```

浏览 `http://127.0.0.1:5173/?streetview&campaign=v2`。免费检查内容清单：

```sh
npm run verify:city-routes
```

带 `--live` 的验证会调用 Google Maps 并可能计费，因此必须在明确授权后运行：

```sh
PUPPETEER_FROM=/path/to/node_modules node self-created/verify-city-chapters.mjs --live
```
